# HCD housing element review letters

5,594 review letters from HCD's [Housing Element Download Tool](https://www.hcd.ca.gov/housing-open-data-tools/housing-element-download-tool) review-letter page. 2,154 have their full text in [`letters/`](letters/); 3,434 are listed as "Contact HCD" with no public copy. Updated automatically; see [CHANGES.md](CHANGES.md) for the latest run.

Search the text with GitHub's search box ("In this repository"), e.g. `"sites inventory" path:he_letters/letters`.

Of letters with a finding, HCD found 1,258 out of compliance and 849 in compliance. Median 58 days from submittal to letter.

Finding: HCD's in/out label in the letter's file name, else wording in the letter. Submittal date: the "received for review" date stated in the letter, else the matching submittal on the Download Tool.
